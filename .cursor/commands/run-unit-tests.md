# run-unit-tests

## Overview
This runs all unit tests and returns the number of passing and failing tests. Failing tests should not be automatically fixed. Instead, failing tests should be retured in a list.

## Steps

1. **Run Unit Tests**
    - Run all unit tests. These should be located in a folder named "tests" and file names should start with "test_"
2. **Generate Result**
    - Create and return a result that includes the number of units tests that passed and the number that failed. If any tests failed, also include the failing test names as a list.
