# investigate-and-fix-test

## Overview
This looks into the cause of a test failure, investigates solutions, and presents any/all solution options. Also, if additional tests should be added then this can also be suggested. If potential solution is chosen, then the fix it outlines is implemented.

## Steps

1. **Investigate Failing Test**
    - Discover the root cause of a failing test and determine different ways to get the test to pass, or it can also be determined that the test is obsolete and should be removed.
2. **Offer Solutions**
    - Provide one of more potential solution to get the test to work. Only if the test is obsolete (meaning it tests functionality that is no longer used or present) can removing it be a potential solution.
3. **Fix Test**
    - (optional) Implement a selected fix from the potential solutions provided in step 2.
4. **Suggest Additional Tests**
    - (optional) List any additional tests that could improve testing coverage, knowing that in many cases there will be no addition tests needed.
