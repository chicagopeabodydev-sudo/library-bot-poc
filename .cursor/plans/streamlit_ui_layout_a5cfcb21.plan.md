# Streamlit UI Layout Plan

## Goal

Align the Streamlit app with the UI description in `[.cursor/commands/project-overview.md](/Users/peabody/Documents/repos/library_bot_poc/library_bot_poc/.cursor/commands/project-overview.md)` by changing `[streamlit_app.py](/Users/peabody/Documents/repos/library_bot_poc/library_bot_poc/streamlit_app.py)` from a single-column chat page into a two-column layout with a centered chatbot image on the left and the chat interface on the right.

## Current State

`[streamlit_app.py](/Users/peabody/Documents/repos/library_bot_poc/library_bot_poc/streamlit_app.py)` currently:

- renders `st.title(APP_TITLE)` and `st.caption(APP_CAPTION)` near the top
- renders all chat history directly in the main block with `st.chat_message(...)`
- uses Streamlit's default assistant message avatar/icon

Relevant existing code:

```72:127:streamlit_app.py
def main() -> None:
    """Render the Streamlit RAG chat UI."""
    load_dotenv(override=True)

    st.title(APP_TITLE)
    st.caption(APP_CAPTION)
    ...
    for message in st.session_state.messages:
        with st.chat_message(message["role"]):
            st.write(message["content"])
            render_sources(message.get("sources", []))

    if prompt := st.chat_input("Ask about the indexed content"):
        ...
        with st.chat_message("assistant"):
            ...
```

## Planned Changes

1. Remove the visible page heading by deleting the `st.title(APP_TITLE)` call while keeping `page_title=APP_TITLE` in `st.set_page_config(...)` so the browser tab title stays intact.
2. Replace the single main-column rendering with `st.columns(...)` inside `main()` to create left and right vertical containers within the main content area.
3. Render the provided asset at `[assets/images/S_Calvin_Information_Desk.png](/Users/peabody/Documents/repos/library_bot_poc/library_bot_poc/assets/images/S_Calvin_Information_Desk.png)` in the left column and center it visually using Streamlit layout plus a small CSS helper if needed.
4. Move the existing caption, chat history loop, source rendering, spinner, and `st.chat_input(...)` flow into the right column so the conversation remains functionally unchanged.
5. Inject a targeted CSS rule in `[streamlit_app.py](/Users/peabody/Documents/repos/library_bot_poc/library_bot_poc/streamlit_app.py)` to hide the assistant chat avatar/icon generated by `st.chat_message("assistant")` without affecting user messages.
6. Keep the sidebar behavior unchanged unless the new layout reveals spacing issues that require a minimal style adjustment.
7. Run lints on the edited file after implementation to catch any issues introduced by the layout refactor.

## Notes

- The safest implementation is to keep all current query/session logic intact and only reorganize where it is rendered.
- The avatar removal is best handled by CSS because the icon is produced by Streamlit internals rather than explicit markup in this file.
- A left-narrow/right-wide column ratio such as `1:2` or `1:3` is likely appropriate, with the exact ratio chosen during implementation based on image fit and chat readability.
